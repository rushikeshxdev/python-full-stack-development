# Week 01 — Python Fundamentals & Introduction to Web Development

## Project Objective

Build a strong Python foundation essential for Backend Development.

---

## High Level Coverage

The following Python and backend fundamentals are covered during Week 1:

- Python syntax
- Variables
- Data types
- Operators
- Conditions
- `for` and `while` loops
- Functions
- Parameters and arguments
- Return values
- Scope
- `*args` and `**kwargs`
- Type hints
- Lists
- Tuples
- Sets
- Dictionaries
- List comprehensions
- Dictionary comprehensions
- File I/O
- File modes
- JSON
- Serialization and deserialization
- Exception handling
- Modules and packages
- Classes and objects
- Constructors
- Inheritance
- Encapsulation
- Polymorphism
- Virtual environments
- `pip` and package management
- Introduction to Flask
- Basic backend-like standalone applications
- CRUD operations
