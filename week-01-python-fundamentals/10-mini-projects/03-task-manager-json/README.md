# Mini Project 3 — JSON Task Manager

## Objective

Build a console-based Task Manager using Python with persistent JSON
storage.

## Features

- Create task
- View all tasks
- Find task by ID
- Update task
- Delete task
- Store tasks in JSON
- Handle invalid input and file errors

## Concepts Used

- Python functions
- OOP
- Classes and objects
- Type hints
- Modules
- Exception handling
- File I/O
- JSON
- CRUD operations

main.py
   ↓
