# Mini Project 1 — To-Do List

## Objective

Build a simple console-based To-Do List application using Python.

## Concepts Used

- Lists
- Dictionaries
- Functions
- Loops
- Conditions
- User input
- Basic exception handling

## Features

- Add task
- View tasks
- Mark task as completed
- Delete task
- Exit application

## Storage

Tasks are stored in memory for this version.
JSON persistence will be introduced in the Task Manager project.
