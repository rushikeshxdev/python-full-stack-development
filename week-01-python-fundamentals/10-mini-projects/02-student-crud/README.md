# Mini Project 2 — Student CRUD

## Objective

Build a console-based Student Management application using Python.

## Concepts Used

- Lists
- Dictionaries
- Functions
- Loops
- Conditions
- User input
- CRUD operations
- Exception handling
- Type hints

## CRUD Operations

- Create student
- Read/list students
- Find student
- Update student
- Delete student

## Storage

Students are stored in memory using a Python list.

JSON persistence will be implemented later in the Task Manager project.
