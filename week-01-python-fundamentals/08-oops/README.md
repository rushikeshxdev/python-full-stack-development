# Task 8 — Object-Oriented Programming (OOP)

## What is OOP?

Object-Oriented Programming is a programming approach where we organize
code around objects that contain data and behavior.

## Important OOP Concepts

### Class
A blueprint/template for creating objects.

### Object
An instance of a class.

### Constructor
`__init__()` is called when an object is created and is commonly used
to initialize object attributes.

### Encapsulation
Keeping data and related methods together and controlling how data is
accessed or modified.

### Inheritance
A child class can reuse and extend functionality from a parent class.

### Polymorphism
The same method/interface can behave differently for different objects.

## Why OOP?

OOP helps us:
- Organize complex applications
- Reuse code
- Separate responsibilities
- Improve maintainability
- Model real-world entities
