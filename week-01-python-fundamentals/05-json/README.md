# Task 5 — JSON

## What is JSON?

JSON stands for JavaScript Object Notation.

It is a lightweight text-based format commonly used to store and exchange
structured data between applications.

JSON is very common in web development and APIs.

## JSON Data Types

JSON supports:

- String
- Number
- Boolean
- Null
- Object
- Array

Examples:

```json
{
    "name": "Rushikesh",
    "age": 23,
    "is_developer": true,
    "skills": ["Python", "JavaScript"],
    "experience": null
}
